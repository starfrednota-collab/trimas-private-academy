# Trimas Private Academy Website

A responsive, professional static website for **Trimas Private Academy**, ready for GitHub Pages.

## Files

- `index.html` — website structure/content
- `style.css` — responsive design
- `script.js` — mobile navigation, animations and current year
- `assets/school-community.jpg` — supplied school/community photo
- `assets/school-leadership.png` — supplied leadership photo
- `assets/logo.svg` — simple Trimas website logo

## Publish on GitHub Pages

1. Create a new GitHub repository, for example `trimas-private-academy`.
2. Upload **all files and the `assets` folder** while keeping the folder structure.
3. Open **Settings → Pages**.
4. Under “Build and deployment”, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub to publish the site.
7. Your website will be available at the GitHub Pages address shown by GitHub.
